# 전체 브랜치 기여 재점검

2026.09.07 기준 원본 저장소에서 `git fetch origin`을 완료한 뒤 로컬 브랜치와 원격 추적 브랜치를 모두 확인했습니다. GitHub 계정은 `junido7185`이며, 이 저장소에 기록된 Git 작성자 이름은 `dev_slime`입니다. GitHub 사용자명 문자열만 검색하면 이 작성 이력을 놓칠 수 있어 기존 커밋의 작성자 이메일을 기준으로 대조했습니다.

총 29개 작성자 일치 기록을 확인했습니다. 일반 개발 커밋 25개, 병합 커밋 2개, GitHub Desktop stash 관련 기록 2개입니다. 삭제된 브랜치의 복구 불가능한 커밋이나 로컬에 존재하지 않는 이력까지 확인했다는 의미는 아닙니다.

## 추가한 범위

- 일기 조각 조합과 분노방 연타 퍼즐 원본 2개.
- 현재 코드에서 빠졌던 카메라·이벤트·대화·플래그·선택지·이동·포털·디버그 기여 발췌 10개.
- 다른 브랜치에 남아 있는 달리기·스태미나 초기 구현 및 컷신 실험 코드 발췌 2개.

현재 기준 커밋의 `Assets/Scripts`에서 Git blame이 `dev_slime`으로 기록한 비어 있지 않은 줄은 기존 파일과 추가 발췌를 합쳐 모두 포함했습니다. 줄별 작성 이력은 선별 근거이며, 팀 공통 설계나 재정렬된 코드의 단독 저작권을 증명하지는 않습니다. 발췌는 원본 순서와 위치를 보존하며 생략된 팀 코드를 재구성하지 않습니다.

일반 개발 커밋은 최종 상태의 구현을 우선 수록했습니다. 중간 버전의 같은 기능을 커밋마다 중복 복사하지 않았습니다. 현재 통합본에 없는 다른 브랜치의 구현은 `Scripts/Historical`에 구분했습니다. 원본 위치와 범위는 [소스 목록](source-manifest.json), 브랜치 기준점 및 기계 검증용 기록은 [전체 점검 기록](commit-audit.json)에 있습니다.

`608c01a`의 FadeManager 변경은 디버그 로그 삭제입니다. 별도의 기능 구현 발췌 대신 이 문서에 유지보수 작업으로 기록했습니다. `098c194`와 `cef941f`는 중복 프로젝트 디렉터리의 추가·제거를 포함하며 복사된 코드 전체를 개인 기여로 처리하지 않았습니다.
